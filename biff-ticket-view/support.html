확장 버전, Chrome 버전, 발생한 문제와 재현 순서를 알려주세요. 비밀번호·예매번호·모바일티켓 URL·QR 코드·결제정보는 보내지 마세요. 화면을 첨부할 때도 해당 정보를 가려주세요.

공개해도 되는 오류나 개선 제안은 GitHub Issues에 남길 수 있습니다. 계정이나 예매 관련 개인정보는 공개 이슈에 쓰지 마세요.

화면이 나타나지 않나요?

  1. 데스크톱 Chrome과 최신 확장 버전인지 확인합니다.
  2. BIFF 예매 사이트에 로그인합니다.
  3. 확장에 해당 사이트 접근을 허용하고 예매 목록 페이지를 새로고침합니다.
  4. 예매한 영화의 관람 월을 선택합니다.

조회에 실패하면 오류 문구와 원래 목록이 표시됩니다. 원래 사이트에서 예매 상태를 확인해 주세요.

필터와 위치는 언제 유지되나요?

같은 탭에서 상세보기와 목록을 오갈 때 복원합니다. 여러 탭이나 기기 간 동기화는 제공하지 않습니다. 선택한 관람 월을 기준으로 조회합니다.

저장 상태를 지우고 싶어요

확장을 끄고 예매 사이트의 저장 데이터를 Chrome 설정에서 삭제하세요. 원래 사이트의 로그인 상태에도 영향을 줄 수 있습니다. ‘필터 초기화’나 확장 삭제만으로 웹사이트의 임시 저장소까지 모두 지워진다고 보장하지 않습니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.

예매 취소·환불 문의

취소 가능 여부, 수수료, 좌석, 환불은 원래 예매 서비스에서 확인해 주세요. 확장 개발자는 예매를 변경하거나 환불할 수 없습니다.
